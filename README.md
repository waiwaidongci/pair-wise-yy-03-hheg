# SceneForge 浏览器三维场景编辑器

技术栈：React、TypeScript、Vite、Three.js、React Three Fiber、Drei、Zustand、MUI、Leva。

## 功能

- 添加程序化几何体、灯光和透视相机，不依赖外部模型。
- 在层级树中拖拽对象建立或取消父子关系，并跟随父级变换。
- 使用移动、旋转、缩放控件编辑对象，支持步长吸附和三轴对齐。
- 编辑材质颜色、粗糙度、金属度、透明度、线框和阴影参数。
- 场景保存为 JSON（v2，含修订信息）并可重新加载。
- 提供 InstancedMesh 批量渲染模式，可添加 240 个对象进行压力验证。

## 离线协作与合并

团队各自离线编辑同一份展台后，通过「导入合并」把文件合回当前场景：

- 场景对象、父子层级、材质等字段按修订追踪，导出文件携带修订历史与字段戳。
- 三方合并：只有一边改过的字段直接采用；同一对象同一字段双方都改过则弹出冲突列表逐条裁决（可全部用我方/对方）。
- 删除会留下墓碑，已移除的对象不会因为导入旧文件而复活。
- 合并结果自动校验父子层级：悬空父级回到根节点，环路自动断开，无法修复则合并失败。
- 合并失败保留当前现场，可重试；冲突未裁决前场景不落地。
- 旧版（无修订信息）场景文件先迁移兼容再读入。
- 对象层级或属性一变，世界包围盒与导出预览即失效重算（状态栏与「预览」对话框可见）。
